# EngineCore Regression Test Library

## Test 001 — Ansul R-102 Tilt Skillet Modular Coverage

### Question

Can I cover a 24" x 36" tilt skillet with 2 x 3N nozzles on an Ansul R-102 system?

### Expected Scope

- Manufacturer: Ansul
- System: R-102
- Appliance: Tilt skillet / braising pan
- Proposed layout: Two 3N nozzles
- Appliance dimensions: 24" x 36"

### Expected Reasoning

EngineCore should:

1. Identify the applicable Ansul R-102 tilt skillet or braising pan coverage method.
2. Verify whether tilt skillets use the fryer-with-dripboard coverage basis.
3. Calculate two proposed modules:
   - 24" x 18"
   - 432 square inches each
4. Compare each module against the applicable 3N limits.
5. Verify the exact manufacturer rule permitting this appliance to be divided into two modules.
6. Verify nozzle placement, aiming, height, lid clearance, flow numbers, and piping limits.
7. Review applicable code and standards.
8. Identify any missing governing evidence.

### Expected Determination

Conditionally acceptable only if the exact R-102 multiple-nozzle modularization rule permits the proposed two-module layout.

EngineCore should not treat the mathematical fit alone as sufficient proof.

### Failure Conditions

This test fails if EngineCore:

- Approves the layout based only on area calculations.
- Does not verify the modularization rule.
- Does not identify nozzle placement and flow-number requirements.
- Hides missing governing evidence.
- States that no conflict exists when review is incomplete.

### Current Result

EngineCore correctly calculated two 24" x 18" modules at 432 square inches each and compared them with the stated 3N limits.

Improvement required:

Direct retrieval and citation of the exact modularization rule before final approval.
