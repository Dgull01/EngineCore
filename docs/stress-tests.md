# EngineCore Governance Stress Tests

Stress tests validate the integrity of EngineCore under difficult conditions.

Passing ordinary questions is insufficient.

EngineCore must also behave correctly under uncertainty, ambiguity, conflicting evidence, and external influence.

## Standard

A failed stress test becomes permanent engineering work.

A corrected stress test becomes a permanent regression test.

The stress test library continuously expands.

It is never reduced.
