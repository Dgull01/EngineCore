Isometric pipe verification

Every pipe piece has a place in the calculation.

A drawing alone cannot settle a close pipe-volume question. EngineCore records the actual network, identifies each piece and relevant fitting, and applies the calculation method in the controlling manufacturer instructions.

When it is useful

Use exact measurements where the margin is uncertain.

A detailed inventory is most useful when the apparent pipe volume is close to the system's limit, the field route differs from the drawing, or an added branch could change the calculation. The applicable manufacturer instructions control which measurements and fittings count.

01 · Trace

Record the network

Identify the cylinder or supply, branches, endpoints, pipe pieces, fittings, sizes, and measured lengths. Unknown field conditions remain marked open.

02 · Tag

Draw one connected model

Give each piece and component a tag. The isometric and physical parts list refer to those same tags, so a reviewer can follow each item back to the record.

03 · Verify

Apply the source method

Use the identified manufacturer, model, and manual revision. Report the calculation basis, result, reviewer confirmation, and limits of the available evidence.

Exact work depends on the system.Some manufacturers use pipe volume, equivalent length, flow points, or other limits. EngineCore applies only the checks supported by the controlling instructions for the identified system and does not assume that one manufacturer's method fits another.
Optional proposed repair scope

A second isometric for the section that would change.

If a small section needs to be added or modified, the proposed work can be documented separately from the existing network. Repair tags identify only the planned pipe pieces and components; the accompanying list gives quantities and part details for that section.

Existing and proposed stay distinct.

The as-found drawing records the observed system. The repair drawing describes a proposed configuration and does not state that any work has been installed, tested, inspected, or approved.

Field measurements and the exact manufacturer source are required before a repair list can be issued as a verified scope. Pipe verification and repair planning are quoted separately from the $199 base Site Compliance Review.
